# みずのまち ひなんナビ（デモ・監修前の試作）

小学生向けの水害避難学習デモです。**1ファイルだけで動きます**（外部との通信はありません）。

遊ぶ: https://YanaiHirotaka.github.io/suibo-demo/

## 重要なおことわり

**これは監修前の試作です。防災の判断に使わないでください。**

- 舞台は二子玉川（PLATEAU の都市データから作成）ですが、**浸水の表現・避難経路・警戒レベルの
  行動文は、いずれも監修を受けていません**
- 経路は機械生成した候補で、**安全を保証するものではありません**
- 観測値（河川水位・雨量）は**模擬データ**です。実際の値ではありません
- 画面には常時「学習用のシミュレーション（監修前・観測値は模擬）」と表示されます

実際の避難の判断は、お住まいの自治体が出す避難情報と、指定緊急避難場所の案内に従ってください。

## 操作

| | |
| --- | --- |
| 移動 | W A S D（タブレットは画面左の指わっか） |
| 地図 | M |
| 話す | E |
| ヘルプ | H |
| 一時停止 | Esc |

読み込みに20〜25秒かかります。
